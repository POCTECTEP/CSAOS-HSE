Выполнил студент группы ПСАПР-25-2 Оберемок Артём
### Задание

Напишите на Python программу, показывающую информацию о файловой системе и информацию о выбранном файле.
1. Подключите модули os и stat, изучите документацию для этих модулей.
2. Напишите функцию для вывода информации о файловой системе:
    - тип файловой системы
    - размер блока
    - количество блоков
    - количество свободных блоков
    - количество inode
    - количество свободных inode и т. п.
3. Напишите функцию для вывода информации о выбранном файле:
    - inode
    - тип файла
    - атрибуты файла
4. Сравните вывод информации для нескольких файловых систем по выбору. Например, для NTFS на хосте и ext3 на ВМ.

#### Чек-лист самопроверки

- Программа запускается без ошибок.
- Выводится информация о файловой системе.
- Выводится информация о выбранном файле.
