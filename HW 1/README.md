## Домашнее задание 1 по дисциплине «Архитектуры ВС и операционные системы»
Выполнил студент группы ПСАПР-25-2 Оберемок Артём
### Задание

Напишите код, реализующий механизм «производитель и потребитель» с помощью общей памяти (shared memory).
1. Создайте функции производителя и потребителя.
2. Выделите буфер общей памяти. За общую память в Python отвечает модуль mmap.
3. Запустите производителя и потребителя в отдельных процессах, передав им в качестве параметра буфер. Потоки можно реализовать с помощью модуля multiprocessing.
4. Производитель должен отправить строку, а получатель должен её принять и вывести на экран.

Убедитесь, что у вас установлены модули mmap и multiprocessing для корректной работы.

#### Чек-лист самопроверки

- Программа запускается без ошибок
- Производитель отправляет данные
- Получатель принимает данные, отправленные производителем, и выводит их на экран
